The default dashboard shows recorded real Nebius inference. Label this evidence as recorded; free scripted simulation is a separate mode. Use the final rendered video only after checking its narration, captions, and measured claims.

## 0:00–0:20 — Problem

“An AI support agent can sound helpful and still refund the wrong person's order. Blocking every request is not a solution either. Wind Tunnel measures violations and useful outcomes.”

Show the dashboard and run source/model.

## 0:20–0:45 — Positive control

Open an ordinary refund, its tool arguments, and the actual tool result. Explain that the orders and transactions are synthetic.

## 0:45–1:25 — Pressure test

Open a real observed live finding. Trace the request to the prohibited call and policy decision. If no violation occurred, state that honestly and show correct handling. Never substitute a scripted failure for model evidence.

## 1:25–2:00 — Application boundary

Compare identical cases with enforcement. Show attempts versus executed actions and whether legitimate refunds still complete. Enforcement does not prove the model improved.

## 2:00–2:30 — Evidence

Show measured tokens, request counts, latency, estimated cost, and JSON export. The cost uses supplied prices and is not a billing statement.

## 2:30–2:50 — Build and limits

Show the repository and exact Nemotron model on Nebius. Mention bounded execution, deterministic checks, and limits: one workflow, twelve fixed cases, known-marker privacy checks. Finish on the dashboard.
